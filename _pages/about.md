I’m a Senior Software Engineer focused on scalable data platforms and distributed systems. I currently build attribution and reporting products for Walmart Connect, using Spark/Scala pipelines orchestrated with Airflow on GCP.

Previously, I worked at Goldman Sachs in Compliance Big Data Engineering, where I improved the performance of a cross-trade workflow from ~2 minutes to ~10 seconds per transaction using distributed processing techniques. I’ve also worked on production tooling in Rust at Meta, and on large-scale data/streaming systems earlier in my career.

Core interests: distributed data processing, performance engineering, and reliable production systems.
